                      Sync with GitHub

                      Keeps your data in a private GitHub repository, so your phone and computer share the same budget. Changes made on two devices are merged entry by entry. Use a fine-grained token limited to this one repository, with only “Contents: Read and write”. The token is stored in this browser, so don’t connect on a shared device.
